# Code of Conduct

## Our values

If you care about NTN workers, you're already a mix between a developer ana Notion power user.
We're building a tool that makes worker development easier. 
Here's how we do it together:

- **Pragmatic** — we care about what works, not what's perfect. Questions and ideas from all skill levels are welcome.
- **Respectful** — treat other people as you'd want to be treated. Disagreements are okay; hostility isn't.
- **Beginner-friendly** — we all started somewhere. No gatekeeping, no "you should already know this."
- **Focused on the tool** — discuss the code and features, not the person. Keep feedback constructive.

## Enforcement

This is a small, volunteer-maintained project. If there are issues—spam, hostile behavior, or attempts to derail discussions—we'll address them directly. Our primary focus is keeping the codebase clean and the tool functional.

## Questions or concerns?

Open an issue or reach out directly. We want this to be a welcoming place to work on worker tools.
